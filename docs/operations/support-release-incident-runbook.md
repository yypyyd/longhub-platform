# 客服、故障升级、版本公告与紧急停发流程

P0：密钥泄露、跨租户、越权执行或数据损坏；立即停发/停用受影响策略，15 分钟内升级安全与负责人。
P1：大面积无法聊天、更新回滚或模型成功率显著下降；30 分钟内升级值班工程师。P2/P3 进入正常工单。

客服只收集授权码尾号、公开错误码、版本和用户主动导出的脱敏诊断；不得要求聊天全文、Token、API Key、
Credential Manager 内容或整个 userData。公告包含影响版本、开始时间、用户动作、已知数据影响和下一次
更新时间，不披露密钥或攻击细节。

发布按内部→5%→25%→100% 灰度，每阶段检查异常退出率、模型成功率/TTFB、升级健康和固定错误码。
触发阈值即在 Admin 暂停 rollout 或紧急停用策略，不删除上一稳定版。恢复后验证下载摘要/签名、真实聊天、
设备授权、Agent 切换和回滚，再恢复灰度。每次事件保留时间线、决策、证据、根因和行动项。
