# 龙枢用户协议要点（法务审批草案）

> 历史/废弃：本文仍包含旧产品概念，仅作法务清单存档，不作为 clean-launch 首发上线流程。

正式协议至少覆盖：服务主体与适用法律；账号、设备授权码和管理员责任；智能体生成内容不构成法律、
医疗、财务或人事最终决定；企业连接器与高风险操作需人工确认；模型供应商和第三方 Pack 的责任边界；
套餐、额度、续费、退款与税务；可接受使用；知识和用户内容权属；保密、数据处理与安全事件通知；
服务变更、停发、终止、责任限制和争议解决。

本文件只作为产品与法务核对清单，不能直接展示为已生效协议。运营主体、价格、司法管辖、联系方式和
供应商清单确定后必须由合格法律顾问批准并版本化发布。
