# 龙枢隐私说明（商用审批草案）

> 历史/废弃：本文仍描述旧 Desktop/Pack/知识库架构，仅作合规草案存档，不作为 clean-launch 首发
> 隐私通知或数据处理实现的依据。

龙枢本地保存聊天、会话、记忆、智能体 workspace、Pack 和更新恢复状态；这些数据位于龙枢独立
userData，不读取或合并用户原有 `~/.openclaw`。模型请求经龙枢 Cloud 代理转发给管理员配置的 OpenAI
兼容供应商，供应商处理规则由企业合同和所选区域决定。

自动遥测只包含软件版本、平台/架构、粗粒度启动/Agent 数量桶、Gateway/更新结果、上一进程退出枚举
和固定产品错误码。Cloud 模型健康指标只保存 API 类型、结果、TTFB 桶和 count。两者不上传提示词、
回答、聊天、文件、工具输入输出、URL、本机路径、端口、PID、异常或堆栈。

管理员启用知识库时，企业上传的正文按租户隔离，用于返回来源明确的引用片段。模型计费用量按设备、
租户和策略聚合 Token/估算 Token/成本，不保存请求或响应正文。用户主动导出的诊断 JSON 不会自动上传。

数据主体请求、法定主体、联系方式、实际供应商、处理区域、保留期和跨境条款必须由运营主体与律师在
正式发布前填写并批准；本草案不是已生效法律文本。
