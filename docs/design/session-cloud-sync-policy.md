# 会话云同步决策与数据边界

状态：已评估，1.0 默认不启用。

会话同步不是一键智能体切换的前置条件。当前会话、记忆和 workspace 继续保留在龙枢独立 userData，
避免在尚无端到端密钥管理、删除证明和跨设备冲突模型时扩大企业数据面。

未来启用必须同时满足：每租户独立数据密钥与信封加密；服务端永远不混用租户索引；Agent/Profile ID、
会话 ID 和内容绑定且不可热改身份；用户删除在活动库、索引、缓存和备份保留期内可追踪；默认保留期
由租户明确配置；导出与恢复均写审计；设备丢失可撤销密钥；同步冲突不得合并不同 Agent 的消息或记忆。

在这些条件完成前，Cloud 不提供会话上传接口，遥测、知识库和诊断接口也不能被复用为隐式会话同步。
