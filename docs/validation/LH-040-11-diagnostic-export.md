# LH-040-11 一键脱敏诊断导出验收记录

> 日期：2026-07-30  
> 状态：代码与自动化验收完成；未部署、未重打候选  
> 线上版本：0.3.7（保持不变）

## 目标

让用户在龙枢产品错误页一键生成可交给管理员或技术支持的本地诊断 JSON，同时避免“先收集全部日志、
再尝试脱敏”的高风险模式。完成后仍直接使用 OpenClaw 原生 `/chat`；不新增业务面板、主 WebUI preload、
Node、通用 IPC 或自动遥测上传。

## 实现结果

### 白名单报告

- 新增 `longhub/diagnostic-export/v1`，字段集合由 TypeScript 结构和构造器固定。
- 只输出应用/OpenClaw/Electron/Node/OS 版本、打包状态、公开短错误码、Gateway 阶段与退避次数、
  runtime-config 来源/尝试次数/版本/过期时间、更新信任/pending 阶段和 Agent 数量。
- 版本只接受 64 字节内安全字符；配置版本只接受规范 ISO 时间或 `unconfigured`。无法证明安全的自由
  文本输出为 `unknown`/`invalid`，不通过通用字符串脱敏后继续保留。
- 报告不读取日志、状态目录、环境变量、Credential Manager、OpenClaw 会话、聊天、用户文件或历史
  错误对象；不含设备 ID、授权码、Token、服务 URL、端口、PID、文件名或本机路径。

### 一键入口与页面权限

- 每个固定产品状态页提供 `longhub-diagnostics://export/` 链接。
- Main 只有在内存状态确认当前窗口正在显示产品状态页时才接受该精确 URL；正常聊天页不能触发。
- query、fragment、URL 凭据、端口、额外路径、其他 host/协议均拒绝；所有新窗口继续禁止。
- 页面保持 `default-src 'none'`、无脚本、无 preload、无 Node、无 IPC。真实 Electron 测试点击链接后
  只产生一次固定导航，由 Main 拦截而不离开错误页。

### 本地文件安全

- Main 使用原生保存对话框，用户明确选择本地 JSON 位置；报告不会自动上传。
- 只接受绝对 `.json` 路径和普通文件目标，拒绝相对路径、符号链接和非普通文件。
- 临时文件使用 PID + 随机 UUID，以 `wx`、`0600` 独占创建后同目录 rename；成功或失败均清理临时文件。
- 日志只记录固定 schema 和报告字节数，不记录报告、保存位置或异常自由文本；失败提示为固定文案。

## 安全决策

- 结构化最小收集优先于自由日志脱敏：未收集的数据不会因为新错误格式或未知秘密而意外泄露。
- 报告不是设备身份、授权证明、远程健康证明或管理指令，接收方不能用它绕过 Cloud 逐请求校验。
- 明文报告由用户主动选择是否分享。已接受的最小信息面包括软件/OS 版本、公开错误码、运行阶段和
  Agent 数量；不包含业务内容或可直接调用服务的凭据。
- 同一 Windows 用户或管理员可以修改自己导出的文件；本功能只保证生成时的字段边界，不签名报告，
  也不把用户提交的诊断当成可信审计证据。

- 首轮入口面向已有固定产品状态页；授权码输入窗口内部的可恢复错误继续由窗口内文案处理，Main 创建前
  的不可恢复更新状态错误仍使用固定原生错误框，后续可复用同一白名单报告但不能扩大采集范围。
