# LH-050 后台统一运营验收记录

日期：2026-07-30  
范围：运行配置、模型策略、额度计量、设备运营、Admin Web、PostgreSQL migrations 009—011、OpenAPI

## 结论

后台统一运营闭环已建立。策略按 `device > plan > tenant > global` 确定性解析，客户端仍只看到
`longhub-default`，真实上游地址、模型 ID 和密钥不会下发。runtime-config 支持十分钟有效期、策略 ETag、
客户端兼容范围、紧急停用、助手文案、快捷任务与固定功能开关；Desktop 使用同源、同设备缓存并严格拒绝
未知字段。

模型代理支持每策略主上游、备用策略引用、0—2 次重试、进程内熔断、请求超时、设备每分钟限速、设备
日额度、租户月额度和设备并发。用量按设备/租户日月聚合输入、输出、缓存 Token、估算 Token 与成本；
上游提供固定用量头时使用实际值，否则以字节数保守估算并显式计入 `estimated_tokens`。

## 安全边界

- 客户端 `model` 始终被服务端覆盖；策略优先级不信任客户端提交的 tenant/plan/device。
- 上游密钥保持 AES-256-GCM 密文；轮换只影响新请求，已取得旧密钥的在途请求不中断。
- 额度和并发在代理发起上游请求前检查；计量不保存提示词、回答、请求/响应正文或 Authorization。
- 设备凭据轮换后旧 Token 立即失效，新 Token 明文只在管理响应中返回一次，日志与审计不记录明文。
- 所有模型策略、助手/功能、设备策略、凭据、Pack/entitlement 和客户端发布变更进入管理员审计。

## 已知扩展边界

单实例速率、并发与熔断状态当前在进程内；多实例上线前需迁移到 Redis/共享限流器。日/月用量已持久化，
但高并发强一致额度需要数据库原子预留或专用计量服务。估算 Token 不能替代供应商账单，财务结算应优先
使用上游实际 usage 或账单对账。

## 自动化证据

- runtime-config：严格 schema、ETag 304 刷新、有效期更新、跨设备/Cloud 拒绝。
- 作用域：设备策略覆盖租户和全局；最低/最高版本与紧急停用关闭失败。
- 模型：固定 model 覆盖、成功/拒绝/超时指标、指标故障不阻断。
- 额度：并发、每分钟速率、日额度、日/月 Token 与成本聚合。
- 设备：停用/恢复、灰度分组、最低版本、凭据轮换、旧凭据失效与审计。

本项不部署线上；生产密钥、共享限流设施和真实计费对账仍属于部署环境材料。
